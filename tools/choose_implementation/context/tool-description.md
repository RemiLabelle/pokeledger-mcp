Demande à l'opérateur de choisir une implémentation lorsque l'agent doit interpréter ou inventer une pièce de logique centrale (fonction, flux de données, structure, algorithme…) qui n'est pas clairement établie par les tests ou la demande. L'agent DOIT fournir la décision à prendre (`decision`), le contexte dans le code (`context`) et au moins une option (`options`) ; chaque option DOIT être un choix éprouvé, aligné sur le code existant, avec sa justification (`rationale`) et un court extrait de code montrant son intégration (`snippet`). L'opérateur choisit une option ou décrit sa propre implémentation. Si `status` vaut "chosen", l'agent DOIT implémenter l'option choisie. Si `status` vaut "custom", l'agent DOIT évaluer l'implémentation de l'opérateur avant de l'appliquer (voir le texte renvoyé). Si `status` vaut "incomplete", l'agent DOIT rappeler cet outil. Pour tout autre `status`, l'agent DOIT s'arrêter et demander à l'opérateur comment procéder. Les mots-clés en majuscules s'interprètent selon le BCP 14 [RFC 2119] [RFC 8174].
