# Revue de code

Cette revue s'applique au changement en cours. Les mots-clés en majuscules
s'interprètent selon le BCP 14 [RFC 2119] [RFC 8174].

Les règles de travail, dont le workflow TDD et sa couverture de 100 %, restent
prioritaires sur les skills de revue ci-dessous : un critère de revue qui les
contredit est écarté. La revue produit des constats et des questions ; elle ne
modifie ni le code ni les tests sans demande explicite de l'opérateur.

[RFC 2119]: https://www.rfc-editor.org/rfc/rfc2119
[RFC 8174]: https://www.rfc-editor.org/rfc/rfc8174
