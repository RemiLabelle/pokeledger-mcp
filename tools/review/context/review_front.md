Renvoie les consignes de revue du code frontend : pipeline de revue fondé sur des preuves, lentilles communes et critères propres à l'interface (vue passive, double envoi). L'agent DOIT l'appeler pour relire un changement frontend avant de le terminer. Le paramètre `mode` est OPTIONNEL : "architecture_audit" ajoute un audit d'architecture, "test_audit" un audit de la suite de tests. Les mots-clés en majuscules s'interprètent selon le BCP 14 [RFC 2119] [RFC 8174].
