Renvoie les consignes de revue du code backend (API Express, Prisma, PostgreSQL, tests d'API) : pipeline de revue fondé sur des preuves, lentilles communes et critères propres au backend. L'agent DOIT l'appeler pour relire un changement backend avant de le terminer. Le paramètre `mode` est OPTIONNEL : "architecture_audit" ajoute un audit d'architecture, "test_audit" un audit de la suite de tests. Les mots-clés en majuscules s'interprètent selon le BCP 14 [RFC 2119] [RFC 8174].
