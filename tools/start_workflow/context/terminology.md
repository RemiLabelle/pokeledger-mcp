# Terminologie

Les mots-clés « DOIT », « NE DOIT PAS », « OBLIGATOIRE », « DEVRAIT »,
« NE DEVRAIT PAS », « RECOMMANDÉ », « NON RECOMMANDÉ », « PEUT » et
« OPTIONNEL » des règles de travail DOIVENT être interprétés comme décrit dans
le BCP 14 [RFC 2119] [RFC 8174] si, et seulement si, ils apparaissent en
majuscules, comme ici. Ils correspondent aux mots-clés anglais suivants :

| Mot-clé français              | Mot-clé BCP 14             |
| ----------------------------- | -------------------------- |
| DOIT, DOIVENT, OBLIGATOIRE    | MUST, SHALL, REQUIRED      |
| NE DOIT PAS, NE DOIVENT PAS   | MUST NOT, SHALL NOT        |
| DEVRAIT, DEVRAIENT, RECOMMANDÉ | SHOULD, RECOMMENDED       |
| NE DEVRAIT PAS, NON RECOMMANDÉ | SHOULD NOT, NOT RECOMMENDED |
| PEUT, PEUVENT, OPTIONNEL      | MAY, OPTIONAL              |

Dans ces règles, « l'agent » désigne l'assistant qui exécute la tâche de code
et « l'opérateur » la personne qui la lui confie.
