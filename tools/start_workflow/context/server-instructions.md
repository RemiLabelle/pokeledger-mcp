Avant de commencer toute tâche de code, l'agent DOIT appeler l'outil
`start_workflow` et DOIT appliquer les règles renvoyées (terminologie,
versionnage, conventions Git, TDD, décisions d'implémentation, commentaires)
pendant toute la durée de la tâche. Les mots-clés en majuscules
s'interprètent selon le BCP 14 [RFC 2119] [RFC 8174].
