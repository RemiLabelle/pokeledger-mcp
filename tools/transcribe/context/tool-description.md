Transcrit un fichier audio mp3 en texte avec ElevenLabs Scribe v2, d'après le skill [speech-to-text](https://tessl.io/registry/skills/github/calesthio/OpenMontage/speech-to-text). L'outil demande à l'opérateur, par un formulaire, le chemin du fichier mp3, l'envoie à l'API ElevenLabs (clé lue dans `ELEVENLABS_API_KEY`) et renvoie la transcription. Le paramètre `path` est OPTIONNEL : l'agent NE DOIT le renseigner qu'avec un chemin donné explicitement par l'opérateur, lorsque l'outil lui demande de le recueillir dans la conversation. Les mots-clés en majuscules s'interprètent selon le BCP 14 [RFC 2119] [RFC 8174].
