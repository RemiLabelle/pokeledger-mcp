Exporte toute la mémoire de `keep_track` dans un paquet JSON versionné (`format: "pokeledger-memory"`, `version: 1`), sans la modifier. L'opérateur conserve ce paquet et le recharge dans une autre session avec l'outil `import_memory` pour reprendre là où il s'était arrêté. Le paquet peut contenir des préférences de l'opérateur : l'agent NE DOIT PAS le publier ni l'envoyer à un service externe. Les mots-clés en majuscules s'interprètent selon le BCP 14 [RFC 2119] [RFC 8174].
